# Структура — план дня

Минималистичный планировщик с тайм-блокингом в духе Structured: день — это вертикальная нить из капсул, высота капсулы растёт с длительностью, свободные окна видны пунктиром, текущий блок заливается цветом по мере хода времени. Входящие, подзадачи, проекты и теги. В «Оформлении» — три монохромные схемы «Тушь» (светлая, с цветными пометками и тёмная «Суми»; по умолчанию — «Как в системе»: пометки днём, Суми ночью), шесть цветных схем с собственной палитрой капсул и выбор шрифтов интерфейса и заголовков. Интерфейс на русском, данные — в `localStorage`.

Оптимизирован под **iPhone 7 / 7 Plus на iOS 15**: без `backdrop-filter`, анимации только через `transform`, корректная высота экрана при нижней панели Safari, крупные зоны нажатия.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

Проверки: `npm run typecheck`, `npm run lint`.

Чтобы открыть на iPhone в локальной сети: `npm run dev -- -H 0.0.0.0` и зайти на `http://<ip-компьютера>:3000`. «Поделиться → На экран «Домой»» запускает приложение без интерфейса Safari.

## Жесты

- **Тап по блоку** — открыть детали.
- **Свайп блока вправо** или тап по кружку — выполнено / вернуть.
- **Долгое нажатие и тянуть вверх/вниз** — сдвинуть блок по времени (шаг 5 минут, у краёв экрана список прокручивается сам).
- **Тап по «Свободно …»** — новый блок в это окно.
- **Свободное время** (песочные часы) — всё лишнее убирается: сколько свободно в границах «моего дня» (по умолчанию 07:00–23:00, меняются в «Настройках»; сегодня — с текущего момента), полоса дня с окнами и кнопки «+30 мин / 1 ч / 1,5 ч / всё окно» для быстрого блока в нужное время.
- **Входящие** (иконка лотка) — задачи без времени, «+» ставит в первое свободное окно.
- **Списки и заметки** (отдельная кнопка) — чеклисты, покупки (отмеченное уезжает «в корзину» и очищается одной кнопкой, список переиспользуется) и заметки-мемо. Пункт чеклиста можно отправить во «Входящие».
- **Прикрепить список** — в редакторе блока выберите готовый список или заметку либо создайте новый чеклист / список покупок прямо для блока (повестка встречи, продукты). На ленте у блока появится значок «☰ 2/5» или «заметка» — тап открывает его. Текст по самому блоку — в его поле «Заметки».
- **Проекты и теги** — в «Настройках».
- **Шторка** закрывается свайпом вниз за шапку, крестиком или тапом по затемнению.

Подробный план реализации и решения под Safari iOS 15 — в [docs/PLAN.md](docs/PLAN.md).
